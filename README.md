# Catatan Mahasiswa

ini aplikasi catatan buat praktikum PWA. 

bisa simpan catatan, edit, hapus, terus ada halaman profil juga buat isi nama, nim, sama kelompok. semuanya disimpan di browser aja (localStorage).

## cara jalanin
buka index.html di browser, atau lebih bagus pake live server biar service worker-nya aktif.

## fitur
- ada 3 halaman: beranda, catatan, profil
- di halaman catatan bisa tambah, edit, hapus
- profil bisa diubah
- bisa diinstall di hp/laptop
- masih bisa dibuka walau offline

## deploy ke vercel
upload folder ini ke github dulu, terus di vercel pilih import project, pilih repo-nya, terus deploy. nanti link-nya dikumpulin sesuai yang dosen kasih.

kalau mau cek offline: buka di chrome, buka devtools, tab network, centang offline, terus refresh. harusnya masih jalan.

dibuat buat tugas praktikum.
